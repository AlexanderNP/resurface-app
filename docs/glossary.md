# Словарь терминов проекта

## ADR (Architecture Decision Record)

Короткая запись одного архитектурного решения: контекст, рассмотренные варианты, принятое решение и его последствия. Пишется в момент решения, чтобы через время можно было понять, почему сделано именно так. В этом проекте каждая запись заканчивается строкой «в продакшене я бы...». Записи лежат в `docs/adr/`.
