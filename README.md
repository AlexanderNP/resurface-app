# Личная библиотека ресурсов

Сервис, который превращает «Избранное» с забытыми ссылками в рабочую библиотеку: сохранение ресурса в один клик, поиск по словам внутри статей и показ связанного сохранённого прямо на странице, которую ты читаешь.

Проект одновременно учебный: на нём отрабатывается System Design на практике (очереди, поиск, кэш, наблюдаемость, надёжность). Каждое решение принимается по замерам и записывается в ADR.

**Статус:** этап 0 — документация. Код появится на этапе 1.

## Проблема

Ресурсы, найденные при изучении технологий, складываются в чат «Избранное». Позже их невозможно найти, и нет повода открыть: фокус уже сменился.

## Как это работает

1. Расширение браузера сохраняет страницу в один клик (необязательное поле «зачем»).
2. Сервер асинхронно получает страницу, извлекает текст и ключевые слова и предлагает категорию.
3. Поиск по словам внутри сохранённых страниц и дерево категорий находят нужное.
4. Контекстный возврат: на любой странице иконка расширения показывает связанные сохранённые ресурсы.
